# Pirate Quest Vertical Slice

The first playable quest is generated by `PirateQuestBootstrap` in `Assets/Scenes/Gameplay/PirateQuest.unity`.

Student flow:

1. Sign in, create an avatar if prompted, and reach Student Hub.
2. Open one of the student's classes to enter its classroom lobby.
3. When the class teacher has unlocked it, select **PLAY PIRATE QUEST**.
4. Move with WASD, look with the mouse, and press E near a gold challenge pedestal.
5. Complete all three navigation questions, then press Enter to return to Student Hub.

Teacher flow:

1. Sign in as a teacher, select a class, and open the teacher class lobby.
2. Use **UNLOCK PIRATE QUEST** to make `The Pirate Voyage` available to that class.
3. Use **LOCK PIRATE QUEST** to remove access again.

The class assignment is stored at:

```text
classes/{classId}/questAssignments/pirate-voyage
```

`StudentQuestLobby` reads this document before it enables the student play button.
`TeacherQuestLobby` additionally checks that the signed-in user matches the class's
`ownerUid` before it writes. Firestore security rules must enforce the same condition
on the server; the client-side check is a usability guard, not authorization.

`QuestLauncher` starts a `QuestSession` before the scene transition. `QuestProgressRepository` writes progress to:

```text
users/{uid}/questProgress/{questId}
```

The record contains quest and class IDs, completed-challenge count, earned XP, completion state, and timestamp. Firestore rules must restrict each learner to their own progress document. XP awards, Hearts, Powers, and teacher unlocks should be authorized by server-side logic or teacher-only writes before production use.

To play an opening cinematic, set the `introVideoUrl` field on `QuestLauncher` to a directly streamable HTTPS media URL. `UrlVideoSequencePlayer` skips an empty or unavailable URL and allows the quest to continue.

The imported pirate source art is under `Assets/Gameplay/Pirate`. Its `Pirate_Full` prefab is assigned as the captain when the setup tool can find it. Re-run **Tools > Imagine Quest > Setup Pirate Quest Integration** after moving or replacing that prefab.
