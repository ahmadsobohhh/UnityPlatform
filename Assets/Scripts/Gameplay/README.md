# Celestial Clock Quest

The playable vertical slice is generated by `CelestialClockQuestBootstrap` in
`Assets/Scenes/Gameplay/CelestialClockQuest.unity`.

Open that scene directly and press Play, or use **Tools > Imagine Quest > Preview
Celestial Clock Quest**. It is deliberately isolated from the existing Student Hub,
Classes, teacher-class, and character-selection pages: the quest setup tool does not
add UI, restyle a Canvas, or modify those established screens.

The Firebase assignment scaffold remains under `firebase/` for a future dedicated
quest menu. It is not deployed or wired into the legacy class pages.

`QuestLauncher` can start a `QuestSession` from a future dedicated quest menu.
`QuestProgressRepository` writes progress to:

```text
users/{uid}/questProgress/{questId}
```

The record contains quest and class IDs, completed-challenge count, earned XP, completion state, and timestamp. Firestore rules must restrict each learner to their own progress document. XP awards, Hearts, Powers, and teacher unlocks should be authorized by server-side logic or teacher-only writes before production use.

To play an opening cinematic, set the `introVideoUrl` field on `QuestLauncher` to a directly streamable HTTPS media URL. `UrlVideoSequencePlayer` skips an empty or unavailable URL and allows the quest to continue.

The imported pirate source art is under `Assets/Gameplay/Pirate`. The Celestial Clock
setup tool uses `Pirate_01` as its captain when that prefab is available.
